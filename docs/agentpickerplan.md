# 智能体荐股池 · 方案

写于 2026-08-07。**这是方案，还没动手。**

---

## 一、先说三件我认为必须先讲清楚的事

### 1. 开源那套（TradingAgents / ai-hedge-fund）不能直接搬

我读了 TradingAgents（Tauric Research，约 6 万星）和 ai-hedge-fund（virattt）。它们
的结构确实值得学——**但两个都明确写着"仅供教育与研究，不用于真实交易"**，
ai-hedge-fund 的 README 原话是 "Not intended for real trading or investment"。

更要紧的是它们跟本站的定位是拧着的：

| | 那两个项目 | 虾米看股 |
|---|---|---|
| 输出 | 买/卖/持有的**决策** | 事实 + 判断依据，**买不买你定** |
| 立场 | 多空辩论后给结论 | 不预测走势、不给目标价、不给买卖时点 |
| 数字 | 模型在推理中生成 | 代码算，模型无权报数 |

照搬会把整个产品的边界推翻。所以**只搬结构，不搬立场**。

### 2. 值得搬的三个结构

- **角色分工 + 阶段化**：不同视角各写各的，再汇总。比一个提示词问八件事强，
  因为每个视角的提示词可以写得很具体。
- **多空对辩**：TradingAgents 的核心机制，也是论文里报告有效的那一条。
  本站已经有同源的东西——反证条件、证据方向轴——**这不是新概念，是把它前置到选股阶段**。
- **风险检查独立成关**：先出候选，再由一个只负责挑刺的环节过一遍。

### 3. 本站已经有一半了

| 智能体要的 | 本站现成的 |
|---|---|
| 基本面分析 | 价值候选（5 套规则）+ 方法体检（8 种方法论） |
| 新闻/事件 | 资讯证据（RSS + 自动对应）、公司公告分级 |
| 情绪 | **缺** |
| 多空辩论 | 投资逻辑的反证条件、证据方向轴 |
| 风控 | 反证命中、复核到期 |

真正缺的只有**情绪那一块**，以及**把它们串起来的编排**。

## 二、数据：已经验过能用，不是"应该有"

三个源都实调过：

| 源 | 覆盖 | 关键字段 |
|---|---|---|
| `stock_comment_em`（千股千评） | **5191 只，全市场** | 机构参与度、综合得分、关注指数、主力成本、排名变化 |
| `stock_hot_rank_em`（东财人气榜） | 前 100 | 当前排名 |
| `stock_hot_follow_xq`（雪球关注） | 5619 只 | 关注人数 |

**千股千评是主力**：它是唯一全市场覆盖的，其余两个只能当补充。

一条要写进代码的边界：**这些是"人气"，不是"好坏"**。人气高往往意味着已经被
充分讨论、价格里已经反映；对价值投资者，高人气更可能是**减分项**而不是加分项。
所以它进模型时必须带着这句话，否则模型会把"热"读成"好"。

## 三、架构：五个角色，一次编排

不做自主循环的 agent（那个不可控、烧钱、且没法解释）。做**固定管线**，
每一步的输入输出都能看到。这是从 TradingAgents 学的形，但去掉了它的自由度。

```
        ┌─ 规则层（代码，不花钱）────────────────────────┐
        │ 5 套价值策略取并集 → 去重 → 打底约 100–200 只   │
        └───────────────────┬────────────────────────────┘
                            ↓ 代码打分，砍到 30 只
        ┌─ 四个视角（各一次模型调用，可并行）───────────┐
        │ ① 生意视角   主营构成、毛利结构、行业位置      │
        │ ② 价格视角   同行分位、方法体检里的价格类方法  │
        │ ③ 事件视角   近期公告、资讯、检索到的公开资料  │
        │ ④ 情绪视角   人气/关注/机构参与度 —— **反向读** │
        └───────────────────┬────────────────────────────┘
                            ↓
        ┌─ 唱反调（一次调用）───────────────────────────┐
        │ 只干一件事：给每只找出**最可能推翻它的那条事实** │
        │ 找不出来的降级 —— 找不到反驳往往是研究不够      │
        └───────────────────┬────────────────────────────┘
                            ↓
        ┌─ 汇总（代码，不是模型）──────────────────────┐
        │ 四个视角各自的结论 + 反调 → 排序 → 出池        │
        └────────────────────────────────────────────────┘
```

**为什么汇总用代码不用模型**：让模型综合四份意见，它会写出一段读起来很像样、
但权重完全不透明的话。用代码是"四个视角里几个说好、反调有没有找到硬伤"，
规则写在明处，你可以不同意并自己改。

## 四、成本（这条决定它可不可用）

按每次跑一遍算：

| 环节 | 调用 | 估算 |
|---|---|---|
| 规则筛 + 打分 | 0 | 0 积分 |
| 四个视角 × 30 只（每批 10 只） | 4 × 3 = 12 | ~12 积分 |
| 唱反调（每批 10 只） | 3 | ~3 积分 |
| **合计** | **15** | **约 15 积分** |

跑之前先给估价，跟深度报告一样。**候选数可调**（30 / 50 / 全部），
积分随之变，让你自己在"看多少"和"花多少"之间选。

## 五、边界（必须写死在提示词和页面上）

1. **不给买卖建议、不给目标价、不给仓位**。输出是"这几只值得你花时间看"，
   跟研究任务的定位一致，不是"买这几只"。
2. **数字由代码给**，模型只读不算——跟深度报告同一条铁律。
3. **人气反向读**：高人气不是加分。写进提示词。
4. **每只必须带一条最可能推翻它的事实**，说不出来的降级。
5. 页面上标明"这是筛选结果，不是推荐"，并写清楚用了哪些数据、哪一天的。

## 六、落地顺序

| 步 | 内容 | 是否花钱 | 状态 |
|---|---|---|---|
| 1 | 情绪数据接入：新表 `market_sentiment`，同步作业，页面能看到 | 否 | **已做**（2026-08-07） |
| 2 | 规则打底 + 代码打分（无模型），先看看纯规则出来的池子像不像样 | 否 | **已做**（2026-08-07） |
| 3 | 四个视角 + 唱反调，接进价值候选页作为第六个"策略" | 是 | 等第 1、2 步的结果再定 |
| 4 | 结果页：每只一张卡（四个视角结论 + 那条反驳 + 数据面小图） | — | 卡片壳已经在了，等第 3 步填内容 |

**建议第 1、2 步先做**：它们不花钱，做完你就能判断"规则打底出来的池子"值不值得
再往上加模型。如果纯规则出来的东西你已经觉得不行，加四个视角也救不回来——
那说明问题在打底的规则，不在缺智能体。

### 第 1、2 步做完之后新知道的事

三件都是真跑数据才冒出来的，方案里没预料到：

1. **东财人气榜（`stock_hot_rank_em`）用不了**：它走 push2.eastmoney.com，
   那条路在部署环境里是被挡的。所以没接——千股千评自带「目前排名」和
   「关注指数」，人气榜本来就是冗余的，接进来只是多一个会失败的依赖。
2. **缺项的权重从分母里拿掉，但不能全拿掉**。只剩一项时那一项自己就是总分：
   一家除了「被规则选中」外什么数据都没有的公司拿 100 分排第一，
   而它跟五项全优的公司在页面上长得一模一样。加了 `MIN_WEIGHT_COVERED = 50`。
3. **行业扎堆只看第一名会漏掉**。申万把银行和保险分成两个二级行业，
   于是「前十里五家银行保险」单看第一名只有 2/10，什么都不触发。
   改成还要看前三名合计——线上实测 6 只时前三占 67%，提示正常出来了。

**第 3 步开工前要先看的**：纯规则出来的这份池子够不够用。
线上跑出来的前几名是锦江航运、芭田股份、青岛银行、成都银行、中国太保、陕西能源，
五项全有数据。如果这份清单本身就不像话，问题在打底规则，加四个视角救不回来。

## 七、我建议不做的

- **自主循环 agent**（自己决定下一步搜什么、算什么）：不可控、成本不封顶、
  出了问题没法复现。TradingAgents 那套用的也是固定图（LangGraph），不是自由循环。
- **回测**：本站没有历史行情的完整快照，回测出来的数字会比真实情况好看得多，
  而一个好看的回测最容易让人下重注。要做得先补数据，是另一个量级的工程。
- **多空辩论打成一个"评分"**：分数会被当成置信度，而它其实只是几个提示词的投票。

## 八、2026-08-08：清单上的四项做完了

顺序是「先做纯代码的、能立刻验证对错的，再做要调模型的」——
前两项算错了当场就能对着年报查出来，后两项要靠约束设计兜底。

### 1. 组合共同风险（纯代码）

**分散不是由只数决定的，是由它们会不会同时出事决定的。**
查六种字面重合：行业分类、**年报分部附注里的同名分部**、产业链共同对手方
（带原始置信度）、估值/市值全市场分位、技术位置、**认错条件里的同一句话**。

最值钱的是分部重合与认错条件重合——前者是真披露数据，两家行业分类完全不同
的公司分部里都写着「光伏组件」；后者是唯一能碰到「共同假设」的：
你为两家公司写的认错条件里出现同一句话，多半是因为心里想的是同一件事。

模型不参与。「这两家算不算同一个风险」编错一次，后果是你据此调仓。

**顺带修好一个真 bug**：ratio 口径（只记仓位占比、不落金额）下 shares 恒为 0，
而「还持有吗」只看 shares > 0——于是一笔 30% 的持仓落进「已清仓」，
组合里一只票都不剩。这是站主自己选的隐私口径，坏了不报错，只是页面空空如也。

### 2. 行业特有指标（纯代码）

ROE 和毛利率对任何公司都能算，也因此对任何公司都说不出多少东西。
白酒看合同负债，银行看拨贷比与净利息收益率，地产看已售未结转覆盖倍数。

**关键发现：三张报表本来就已经全下下来了**（资产负债 147 列、利润 83 列、
现金流 71 列），此前只挑走十几个通用字段，其余全扔——而能分辨生意的那几个数
全在被扔的那部分里。留下来不多花一次网络请求。

口径上守两条：涉及流量的指标**只用年报**（新浪的报表是累计口径，
一季报的分母只有四分之一年）；时点数可以看季报但**跟去年同期比**
（白酒的合同负债在春节后那一季天然是高点）。

行业只做**恰好匹配**，不模糊：把「食品饮料」当成「白酒」算出来的合同负债结论，
对乳制品公司是错的，而它看起来跟对的一模一样。目前覆盖白酒、银行、房地产、证券
四个行业；别的只有三条通用指标，并且明说「这个行业还没有定义专属指标」。

实测：工行拨贷比 2.79%（监管底线 2.5%）、存贷比 81.76%、中间业务占比 13.26%；
茅台合同负债占收入 4.74%、较上年 -0.87 个百分点；万科已售未结转覆盖 0.41 倍。

### 3. 管理层承诺兑现台账（要调模型，抽取从严）

「未来三年现金分红比例不低于 30%」说出口那天是利好、股价会涨，
而到期日没有任何提醒。**一家从不兑现承诺的公司和一家次次说到做到的公司，
在你的档案里长得一模一样。**

跟认错条件是同一个形状：一句话 + 一个到期日 + 一个到期时能核对的条件。

抽取的四条硬规矩（都在代码里，不靠提示词自觉）：
statement 必须是原话；指不到出处的丢掉；推不出到期日**留空不猜**
（猜一个会让台账在错误的那天报「未兑现」）；量化条件缺一个字段就整组作废。

净利润、营业收入、分红比例三类到期自动比对——**那一段是纯算术、不过模型**。
**一条都不会被自动判成「未兑现」**：自动核对只说「对上了/没对上/数据不够」，
而「这家管理层靠不靠谱」是判断，判断由人来下。

### 4. 对话式反方 Agent（要调模型，靠约束兜底）

一个会附和你的荐股 Agent 是这个产品里最没价值也最危险的东西：
你已经买了、已经写了逻辑，多一个声音说"有道理"只是把确信度往上推一格。

三条硬约束，都在代码里：

1. **只能读库。** 八个只读工具，**都不接受 company_id 参数**——
   模型没有办法去查别家公司，更没有办法去查别人的数据。
2. **引不出数据的主张当场丢掉。** 一句听着有道理、其实凭空捏的反驳，
   比没有反驳糟得多——它会让你放弃一条本来对的判断。
3. **只能提议，不能写。** 反证条件只作为初值填进你自己的修订框。

外加数字溯源：它说的每个数回工具返回的原始行里找一遍，找不到的**标出来**
（不是删掉——有些是它算的差值），你就知道该核哪几个。

实测（茅台，逻辑写的是「定价权还在，渠道愿意提前打款」）：
查了 theses / industry_metrics / financials / segments 四张表，19 秒，
给出三条带数据的反方，其中一条指出合同负债占收入从 11.98% 一路掉到 4.74%、
接近 2014 年渠道出清前的水位，并给出可对照的反证条件；
同时明说「定价权那一半查过之后仍站得住，塌的是收入增长和渠道打款意愿」。
它自己算的三个同比百分比被溯源机制正确标成了「找不到出处」。

### 还没做的

- 行业特有指标只覆盖四个行业。加一个行业是加一段声明式定义，不改结构。
- 自动核对只覆盖三个指标（库里只有这三类数据）。回购进度、项目达产要人去看公告。
- 承诺抽取要按公司逐个跑一次（读的是已归档的公告）。
- 存量公司要重新点一次「更新财务数据」，报表原始科目才会落库。
